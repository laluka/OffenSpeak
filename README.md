# OVT - OffenSkill Voice Toolbox

Browser-based Speech-to-Text and Text-to-Speech toolbox. Zero dependencies, single HTML file, works offline.

**Live:** [speak.offenskill.com](https://speak.offenskill.com)

## Features

- **Speech to Text** — real-time transcription via Web Speech API
- **Text to Speech** — word-by-word highlighted playback with voice selection
- English / French language toggle
- Keyboard shortcuts: `Space` (record), `Ctrl+Shift+C` (copy), `Ctrl+Enter` (speak), `Esc` (stop)
- Dark / light mode (follows system preference)

## Usage

Open `index.html` in a modern browser (Chrome, Edge, or Safari recommended).
